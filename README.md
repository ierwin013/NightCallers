# Night Callers

A dark-themed daily production and performance dashboard for the Night Callers team.

Open `index.html` in a browser or publish the repository root with GitHub Pages. Dashboard changes are saved in the browser's local storage. To share changes live with everyone viewing the link, set `SYNC_URL` at the top of `script.js` to a Firebase Realtime Database URL (with read/write rules enabled).

The initial goals, roster, metrics, and team records are seeded from `data.json`. They can be changed from the dashboard.
